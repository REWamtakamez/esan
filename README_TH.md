# Physics Energy AR — โปรเจกต์เว็บ AR สำหรับโมเดลพลังงาน

เว็บ AR ภาษาไทย ใช้กล้องมือถืออ่านภาพเป้าหมาย แล้วแสดงการ์ด AR เรื่องพลังงานจลน์ พลังงานศักย์โน้มถ่วง และการอนุรักษ์พลังงานกล สร้างด้วย MindAR + A-Frame และมีหน้า `make-qr.html` สำหรับสร้าง QR Code หลังเว็บออนไลน์แล้ว

## สำคัญ: ต้องสร้างไฟล์ `targets.mind` ก่อน

ไฟล์ `.mind` เป็นข้อมูลสำหรับติดตามภาพ และไม่ได้สร้างจากรูปถ่ายโดยอัตโนมัติใน HTML ขั้นตอนนี้ทำครั้งเดียว:

1. เปิด MindAR Image Targets Compiler: https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2. อัปโหลดไฟล์ `physics-target.png` ที่อยู่ในโฟลเดอร์นี้
3. กด **Start** รอให้ประมวลผล แล้วกด **Download** เพื่อดาวน์โหลดไฟล์ `targets.mind`
4. วาง `targets.mind` ไว้โฟลเดอร์เดียวกับ `index.html` (ระดับ root) ห้ามเปลี่ยนชื่อไฟล์

## เผยแพร่เว็บให้เปิดจาก QR ได้

วิธีหนึ่งคือ GitHub Pages:

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลด `index.html`, `make-qr.html`, `physics-target.png`, `README_TH.md` และไฟล์ `targets.mind`
2. ไปที่ **Settings → Pages** เลือก deploy จาก branch หลัก (`main`) และโฟลเดอร์ `/ (root)` แล้วบันทึก
3. เมื่อ Pages เผยแพร่เสร็จ จะได้ URL ลักษณะ `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`
4. เปิดหน้า `make-qr.html` ของเว็บที่เผยแพร่แล้ว (เติม `/make-qr.html` ต่อท้าย URL) ใส่ URL หลักของเว็บ AR แล้วกด **สร้าง QR Code** จากนั้นดาวน์โหลด PNG
5. พิมพ์ QR Code ให้ผู้เรียนสแกนเพื่อเปิดเว็บ แล้วอนุญาตกล้อง

เว็บไซต์ AR ต้องเปิดผ่าน HTTPS และต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีจาก CDN

## วิธีใช้งานในห้องเรียน

1. พิมพ์หรือแสดงไฟล์ `physics-target.png` บนหน้าจออื่นเป็นภาพเป้าหมาย
2. สแกน QR Code เพื่อเปิดเว็บ AR บนโทรศัพท์
3. อนุญาตการใช้กล้อง แล้วเล็งกล้องไปที่ภาพเป้าหมายทั้งภาพ
4. เลือกปุ่ม “ภาพรวม”, “พลังงานจลน์”, “พลังงานศักย์” หรือ “พลังงานกล” เพื่อสลับคำอธิบาย

**ข้อจำกัดของการติดตาม:** ภาพ `physics-target.png` ใช้เป็นเป้าหมาย 2 มิติ กล้องควรเห็นภาพเดียวกันหรือภาพพิมพ์ที่เหมือนกัน การเล็งไปยังโมเดลสามมิติจริงโดยไม่มีภาพเป้าหมายอาจตรวจจับไม่เสถียร หากต้องการติดตามตัวโมเดลจริงทุกมุม ควรใช้ระบบติดตามวัตถุ 3 มิติ/marker เพิ่มเติม

## ไฟล์ในโปรเจกต์

- `index.html` — ประสบการณ์ Web AR และการ์ดความรู้
- `physics-target.png` — ภาพต้นแบบสำหรับสร้าง target
- `make-qr.html` — เครื่องมือสร้างและดาวน์โหลด QR Code หลังเผยแพร่เว็บ
- `targets.mind` — **ไฟล์ที่ต้องสร้างและใส่เอง** จากขั้นตอนด้านบน
